# Κανόνες ονομασίας
- Διαδρομές μόνο ASCII· ελληνικοί τίτλοι στη βάση και στο ευρετήριο.
- Μάθημα: `<ΤΑΞΗ>-<ΜΑΘΗΜΑ>` (π.χ. `B-ILEKTROTECHNIA`). Φάκελοι: `01_ODIGIES 02_VIVLIA 03_YLI 04_TRAPEZA 05_PANELLADIKA 06_DIAGONISMATA 07_EXAGOGES`.
- `04_TRAPEZA/orig/`: αρχεία ΙΕΠ ως έχουν (`<ID>.pdf`, `<ID>_SOLUTION.pdf`, προαιρετικά `.docx`). Δεν τροποποιούνται. Εξαίρεση: ο εκπαιδευτικός προσθέτει εδώ τα δικά του αρχεία λύσεων `<ID>.<θέμα>-<υπ>.md` και τις εικόνες τους στο `orig/images/`.
- Λύσεις εκπαιδευτικού: `<ID>.<θέμα>-<υποερώτημα>[-<υπο-υποερώτημα>].md`, π.χ. `17771.2-1.md` (ερώτημα 2.1), `17698.4-1-2.md` (4.1.2). Εικόνες `orig/images/<ascii>.png|jpg|svg`. Παλιός φάκελος `05_LYSEIS/` διαβάζεται για συμβατότητα (το `orig/` υπερισχύει).
- `04_TRAPEZA/derived/<ID>/item.json`: παράγωγα (ερωτήματα). Ξαναφτιάχνονται.
- Δικά μου θέματα: ID `M-0001`· συναδέλφων `S-0001`.
- Αριθμός τυπωμένης σελίδας βιβλίου = σελίδα PDF − `pdf_offset` (1 για το βιβλίο Ηλεκτροτεχνίας).
